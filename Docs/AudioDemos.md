# Listening previews

The website's REVERB, FERAL, RIFT, EMBER, ECHO and CHOIR previews use the published Windows VST3 binaries. Original synth phrases and a drum loop are generated by `scripts/render_audio_demos.py`; there are no external samples or extra effect chains.

The renderer checks each binary against the release manifest, processes 14 seconds of stereo audio at 48 kHz in 512-sample blocks and includes silence after the phrase for the effect tail. Processed audio is matched to the dry source's RMS over the active phrase. If peak headroom requires a reduction, both versions receive the same reduction. Both use the same 192 kbps MP3 encoder settings. The script decodes every encoded file to confirm equal duration, finite samples and no clipping.

The demo manifest records the binary hashes, parameter settings and gain adjustment. RMS matching is a practical comparison aid, not a claim of perceptual LUFS matching or a comprehensive sonic test.

To regenerate, install NumPy and Pedalboard 0.9.25 in a Python environment and FFmpeg from its official distribution, then run from the repository root:

```powershell
python scripts/render_audio_demos.py --plugins "$env:LOCALAPPDATA/Programs/Common/VST3" --manifest releases/manifest.json
```

The released plugins must be installed, with an active trial or licence. Pass `--ffmpeg` with an executable path if it is not on PATH. Windows Pedalboard loads the inner `Contents/x86_64-win/*.vst3` file rather than the outer bundle directory.

The browser player loads only the chosen pair. Both versions play from the same position, with a 25 ms crossfade when switching. Starting another preview pauses the previous one; backgrounding the page also pauses playback. Previews can be paused, resumed and sought with pointer or keyboard controls.
